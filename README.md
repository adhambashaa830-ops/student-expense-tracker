
# 🎒 Student Expense Tracker & Financial Planner

A lightweight web application designed for college students to track expenses, manage budgets, and maintain financial responsibility. Built from scratch to demonstrate core web engineering concepts, DOM manipulation, and dynamic client-side calculations.

## 🚀 Live Demo
You can view the fully deployed web application here: 
👉 [https://github.io](https://github.io)

---

## 📋 Project Objectives & Problem Statement
College students frequently struggle with budget management due to irregular income streams and disparate spending across academic supplies, food, and entertainment. This project addresses the issue by offering a clean, localized interface to monitor balances instantly without requiring a heavy, ad-supported mobile app.

## ✨ Features
* Dynamic Budget Calculations: Automatically calculates expenditures and displays real-time remaining balances.
* Categorized Logging: Organizes expenses into Education, Food, Transport, or Entertainment with distinct color-coded indicators.
* Status-Based Styling: The balance indicator dynamically shifts visual styling (changing color) to warn the student if they overspend past their limit.
* Data Erasure Logic: Built-in row index pointer management allowing students to clear mistakes or past items dynamically.

## 🛠️ Technology Stack Used
* Frontend Structure: HTML5
* Interface Styling: CSS3 (Custom Variables, Flexbox, Responsive Grid Architecture)
* Application Brain: Vanilla JavaScript (ES6+ array manipulation methods like .reduce() and .splice())
